# منصة «مُذكَّرتي» (Mothakarati SaaS Platform)
منصة سحابية متقدمة متعددة المستخدمين لأساتذة مادة اللغة الإنجليزية في الجزائر (الطور المتوسط: 1AM - 4AM).

---

## 🌟 نظرة عامة
تم تصميم المنصة خصيصاً لمطابقة المعايير البيداغوجية الرسمية لوزارة التربية الوطنية الجزائرية، وتوفير تجربة مستخدم سلسة لإعداد، تدقيق، وتصدير مذكرات الحصص اليومية وأغلفة المقاطع التعليمية بدقة بكسل تامة مطابقة للطباعة.

### 📐 الميزات الجوهرية
1. **محرر مذكرات كتل متقدم:**
   - هيكل الصفحة والورقة بأبعاد حقيقية (A4, A3, Letter, Legal).
   - جدول المراحل برأس ذهبي (`Stages` / `Procedures` / `Interaction` / `Time`).
   - بطاقة الحصة الرسمية بالحقول المعتمدة (العنوان بالأسود، القيمة بالأحمر).
   - الحفظ التلقائي وميزة التراجع والإعادة (Undo / Redo).
2. **مركز التصدير فائق الدقة (PDF & Word):**
   - مطابقة تامة بين المعاينة والطباعة (Single Rendering Source).
   - تعديل خلفية الـ PDF (رخامي، لافندر، صور مخصصة) والعلامة المائية دون المساس بمحتوى المذكرة.
   - وضع الطباعة الاقتصادي الموفر للحبر (Eco-friendly).
   - تصدير مباشر لملفات Microsoft Word (`.docx`) بجداول حقيقية.
3. **المساعد الذكي البيداغوجي (AI Assistant & RAG):**
   - استناد مباشر إلى وثائق المنهاج الرسمي والتدرجات السنوية 2023/2024.
   - توليد خطة الحصة وفق الهياكل المعتمدة: PPU, PDP, TBL, PIASP.
   - فحص توافق الكفاءات المستهدفة والأهداف التعلمية وإمكانية الفتح الفوري في المحرر.
4. **أمان وعزل كامل للمستخدمين (Zero-Trust & RLS):**
   - عزل تام للمذكرات بحسب هوية الأستاذ ومنع ثغرات الوصول المباشر (IDOR).
   - مخطط قاعدة بيانات Postgres مع Drizzle ORM وسياسات Row-Level Security.
5. **خادم MCP (Model Context Protocol) والمراقبة:**
   - 13 أداة متخصصة للتحكم البرمجي في المذكرات والقوالب والتصدير.
   - نقطة فحص صحة النظام `/api/health`.

## 🚀 التثبيت والتشغيل المحلي

### 1. المتطلبات:
- Node.js 18+ (أو Node.js 20/22)
- pnpm أو npm

### 2. التثبيت:
```bash
git clone <repo-url>
cd mothakarati
pnpm install
```

### 3. إعداد البيئة:
أنشئ ملف `.env.local` وضع الإعدادات التالية:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### 4. تشغيل الاختبارات الآلية:
```bash
pnpm test
```

### 5. تشغيل خادم التطوير:
```bash
pnpm dev
```
افتح المتصفح على: `http://localhost:3000`

### 6. بناء نسخة الإنتاج:
```bash
pnpm build
pnpm start
```
