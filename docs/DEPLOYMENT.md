# دليل النشر على استضافة مجانية (Free Hosting Deployment Guide)

تم تجهيز منصة «مُذكَّرتي» بالكامل لتكون متوافقة بنسبة 100% مع منصات الاستضافة السحابية المجانية، وبالأخص منصة **Vercel** (المطوّرة لإطار عمل Next.js).

---

## 🚀 الخيار الأول (الأسهل والموصى به): النشر عبر Vercel + GitHub

Vercel هي الاستضافة الرسمية والأقوى لـ Next.js وتقدم باقة مجانية دائمة (Hobby Plan) تتضمن:
- نطاق مجاني سريع بصيغة: `https://mothakarati.vercel.app`
- شهادة أمان SSL/HTTPS مجانية وتلقائية.
- نشر تلقائي وسريع عند أي تعديل في الكود.

### الخطوة 1: رفع المشروع إلى حسابك على GitHub
1. ادخل إلى [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) وقم بتسميته مثلاً `mothakarati`.
2. في موجه الأوامر (Terminal) داخل مجلد المشروع، نفذ الأوامر التالية لربط المستودع ورفع الملفات:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mothakarati.git
git push -u origin main
```
*(استبدل `YOUR_USERNAME` باسم المستخدم الخاص بك على GitHub)*.

### الخطوة 2: النشر على Vercel
1. توجّه إلى موقع [vercel.com](https://vercel.com) وسجل الدخول باستخدام حسابك على GitHub.
2. اضغط على زر **Add New...** ثم اختر **Project**.
3. ستجد المستودع `mothakarati` في القائمة؛ اضغط على زر **Import**.
4. سيتعرف Vercel تلقائياً على Next.js:
   - **Framework Preset:** Next.js
   - **Build Command:** `pnpm build`
   - **Install Command:** `pnpm install`
5. اضغط على زر **Deploy** الأزرق.
6. خلال دقيقة واحدة، ستظهر لك شاشة الاحتفال بنجاح النشر ورابط موقعك المباشر!

---

## ⚡ الخيار الثاني: النشر المباشر من موجه الأوامر (Vercel CLI)

إذا كنت لا ترغب في إنشاء مستودع GitHub وتريد نشر الموقع فوراً من جهازك:
1. في موجه الأوامر داخل المشروع، نفّذ الأمر:
```bash
npx vercel
```
2. سيطلب منك تسجيل الدخول إلى Vercel عبر المتصفح لمرة واحدة.
3. اضغط `Enter` للموافقة على الإعدادات الافتراضية.
4. للنشر إلى بيئة الإنتاج برابط نهائي، نفّذ:
```bash
npx vercel --prod
```

## 🛠️ ما تم تجهيزه وتوافقه تلقائياً في المشروع:
1. **نظام الملفات المعزول (Serverless Storage):**
   - تم ضبط مسار التخزين ليتعرف تلقائياً على بيئة Vercel Serverless ويستخدم `/tmp/data` لتفادي أي خطأ في نظام الملفات.
2. **محرك التصدير المرن:**
   - تم ضبط مصدّر PDF ليدعم المعالجة السحابية والطباعة المتجهة العالية الجودة، بحيث يعمل تصدير الـ PDF والـ Word بسلاسة تامة دون الحاجة لسيرفرات مدفوعة.
3. **ملف الإعداد والتجاهل:**
   - تم إنشاء ملف `vercel.json` وملف `.gitignore` لحماية المفاتيح وحجب المجلدات المؤقتة.
